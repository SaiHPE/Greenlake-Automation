## Goal

A run with a *Migration* tab gets a **Migration** step that reads the source array read-only, reads the
destination's peer ports, and shows a readiness report: source facts, hosts and their volumes, blocking
findings and warnings, one sentence each. Nothing is written anywhere. No zoning, no hand-off, no
progress in this slice. **The first family is 3PAR**, on the pair E18U31 (destination) and the lab's
HPE 3PAR 20850 R2 (source); Primera and Alletra 9000 are refused with their sentence until captured.

## Decisions already made (do not reopen)

- The source is a read-only step credential: `ArrayCliClient` only. Never `WsapiClient`, never
  `ArrayRcCliClient` (ADR 0020 §1).
- The run's array is the destination; the tab is refused if the source address equals it (SPEC-027 R1).
- Finding texts, the version table and the check list are SPEC-027 R5. B8 (peer ports) reads
  `showport`; it does not configure anything (SPEC-025 owns that).
- The read client refuses `showtarget ... -rescan`: done in BL-46. `showrsv` is allowed only after its
  help has been read for acting options (SPEC-027 R4, LESSONS 46).
- A source family with no captured output is refused with a sentence, not parsed (R4).

## LESSONS traps

- **33, 36**: the hosts sharing a volume are listed (W1), never silently added or dropped.
- **41**: the persona/OS/existence of a host is derived once, in `read.py`; checks use the flag.
- **42**: the source's `HN:` or host name is a claim; match hosts by WWN, show the name.
- **44**: no check sends anything; `showtarget -rescan` is refused for that reason.
- **46**: an allowlist of names is not an allowlist of actions; read `help showrsv` before allowing it.
- **35**: E18U31's peer ports and their zones to the 3PAR were not made by this project; ask, and read
  the event log, before using them.
- **28**: the parser is pinned to real output, not a hand-written sample.
- **6**: the report is a result; nothing in this slice authorises anything.
- Port Mode `peer` on an IP port is RCIP/cluster, not data migration (both lab arrays show it).
- No ADR/SPEC/version numbers in operator text (`bc605704` pins it for replication; add the same test).
