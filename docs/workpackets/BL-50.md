## Decisions already taken (do not re-decide)

1. The tool never writes to a switch; RCFC zones are a command set for the SAN team (ADR 0012).
2. Reads stay on the read-only client. Every read part A needs (`showport`, `showrcopy`, and later
   `showport -rcfc`, `showrctransport -rcfc`, `showport -c`, `showportdev ns`) is already allowed: the
   read allowlist checks the first word.
3. A partnership is found by what the arrays say about each other (addresses, WWNs), never by target
   name (SPEC-016 R2).
4. A port is judged by its Type, logins and exports, never by its Label (LESSONS 42).
5. RCFC latency limit: 10 ms for sync and for async (Support Matrix, research 2026-10-07 §3).
6. Build part A; part B is deferred (ADR 0024, 2026-11-17).
7. R5 is BL-57's. Do not rebuild it here; build on it once it has merged.
8. One pair, one transport: a pair that shows IP and FC targets towards each other is blocked, never
   used (SPEC-031 R3, LESSONS 44).
