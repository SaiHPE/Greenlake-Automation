# Work packet BL-26 — peer ports for migration

**Goal.** The tool sets chosen free FC ports on this run's array to peer mode, from a *Peer ports* tab
in the workbook, through the usual plan, approval, apply, removal set, verify and as-built. It also
designs the SAN zones those ports need, as a command set for the SAN team (it never writes a switch).

## Decisions already taken (do not re-decide)

1. Only `free` FC ports with no login (`showhost -d`) and no export (`showvlun -a`) are changed. A port
   that serves hosts is a conflict whatever its Label says (LESSONS 42).
2. At least two ports on two different nodes, or the plan blocks. Both ports on one fabric is a note.
3. Commands, in order per port: `controlport offline <nsp>`, `controlport config peer -ct point -f <nsp>`,
   and `controlport rst <nsp>` only if the lab capture shows it is needed. In the first slice the tool
   prints them and a consultant pastes them; the tool runs them only once the write lands.
4. Undo per changed port, pasted by the operator, never run by the tool: `controlport offline <nsp>`,
   `controlport config <old connmode> -ct <old conntype> -f <nsp>`, `controlport rst <nsp>`. The `rst`
   line stays on every port, so a port left offline by a hung `config` comes back. A port held offline
   in its old mode gets `controlport rst <nsp>` only. No `showport -par` read means a blocker. The undo
   is printed (first slice) or written to the run's removal set (the write) before the first command.
5. Zones use the peer port WWPN read **after** the change (the read after the paste, or the apply's
   read-back).
6. No step of its own: peer ports are a section of the *Array ports* step (`ports`, kind `provision`,
   between `discover` and `zoning`) that SPEC-024 (BL-25) proposes. If BL-25 has not merged yet, add
   the `ports` step exactly as SPEC-024 R8 describes it, with the peer-port section only.
7. ADR 0018 accepted 2026-11-17, write deferred: the first slice adds no allowlist form and no write
   client. The read after the paste and the apply's read-back are one function (LESSONS 41).
8. A planned port whose WWPN a zone names in a switch's `cfgshow` gets a note (SPEC-025 R3); the array
   cannot see zones.
