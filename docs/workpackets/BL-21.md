## Goal

After provisioning, the tool takes one snapshot of each volume the workbook names and sets up a
snapshot schedule with an expiry, through the same plan, approve, apply, removal set, verify and
as-built flow as provisioning. The engineer asks for it on a new *Snapshots* tab of the workbook.

## The tests already written

Four files, every test marked `xfail(strict=True)` at module level when written:
`tests/unit/test_snapshots_domain.py`, `test_snapshots_read.py`, `test_snapshots_sheet.py`,
`test_snap_cli_client.py`. Now `test_snapshots_read.py` has no mark (all green, step 2) and
`test_snap_cli_client.py` has one mark per test, each naming the step that turns it green. A strict xfail that starts passing fails the suite. So, in each step:
**delete the module-level `pytestmark` of the file you are working on, and put the same
`@pytest.mark.xfail(reason=..., strict=True)` on each test in that file that is still not green.**
When the last one in a file is green, no mark is left. Never change what a test asserts to make it
pass; if a test is wrong against the spec, ask the owner and say so in the pull request.

Run from the app folder: `.venv/bin/python scripts/check.py` must say PASS after every step.

## Traps (from LESSONS.md)

- **6** — the approval belongs to the plan it was given for. A new read clears the tick.
- **7, 31** — a schedule keeps writing after the run. Say so on the tick, the result and the
  as-built; never hide it behind what the tool did not do.
- **19, 41** — one removal order constant, one name derivation, one cron builder. Do not re-derive
  them in the frontend or the as-built.
- **28, 29** — the WSAPI snapshot body and the quoted `createsched` are proven only by the live run.
  Read the SDK function before calling it; never use the SDK's own `createSchedule` (it uses an SSH
  channel our client never sets up).
- **36** — a blank cell never means "all". A blank source is a refused row, not every set.
- **37** — the snapshot-now name is fixed (`<volume>.initial`) so a rerun finds it. Plan and apply
  judge "exists" from the same read.
- **39** — the removal set's order is a property of the list, and a CLI refusal is judged on the
  array's own words, not on the absence of *Error*.
- **21** — scrub user names from the capture before it is committed.
