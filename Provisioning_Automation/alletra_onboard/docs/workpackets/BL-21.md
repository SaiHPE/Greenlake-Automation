## Goal

After provisioning, the tool takes one snapshot of each volume the workbook names and sets up a
snapshot schedule with an expiry, through the same plan, approve, apply, removal set, verify and
as-built flow as provisioning. The engineer asks for it on a new *Snapshots* tab of the workbook.
